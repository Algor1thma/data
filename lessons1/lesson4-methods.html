Описание на клас – да допълним ☺

В тялото на класа се дефинират полетата (променливите) и методите. Полетата и методите се наричат членове на класа.

  • Полетата се декларират по същия начин, както по-рано декларирахме променливи.
  • Методите се дефинират по същия начин, както беше показано в рамките на обучението в 10. клас.
Да обобщим!
  • Класът е шаблон за създаване на обекти.
  • Обектът е конкретна инстанция, създадена по шаблона на класа.
  • Членовете на класа са неговите полета и методи.
  • Полетата са променливи, които съхраняват данни за състоянието на обекта.
  • Методите са действия, които дефинират поведението на обекта.

Описание на клас – добавяне на методи

Когато за обектите от един клас е типично някакво действие, това действие се описва като метод в рамките на класа. Така описаният метод може да бъде извикан чрез всеки един отделен обект от дадения клас. Няма ограничение за броя на методите, които могат да бъдат описани в един клас.

Описание на класа „Животно“ - недостатък

class Animal { public string kindOfAnimal; public string color; public int numberOfLegs; public bool hasTail; public bool isMammal; }

В главния метод на програмата се налагаше за всеки нов обект от този клас да се изписват едни и същи команди, за да се изведе на екрана информация за обекта! ☹

По-добре е в самия клас да се създаде метод, чрез който да се извежда на екрана необходимата информация за обекта! ☺

Деклариране на метод – да си припомним ☺

[<достъп>] <тип> <име> ([<списък с параметри>]) { <тяло на метода> } Например: public void DisplayStudentData() { … }
  • [<достъп>] – не е задължително да се определи, засега ще използваме public.
  • <тип> - зависи от връщаната стойност:
    • void – не връща нищо, само извършва определена работа;
    • int – връща стойност от тип int;
    • double – връща стойност от тип double;
    • string – връща стойност от тип string;
  • [<списък с параметри>] – не е задължително да има такъв, използва се когато се налага да бъде изпратена информация до метода.

Описание на класа „Животно“ – добавяне на метод

class Animal { public string kindOfAnimal; public string color; public int numberOfLegs; public bool hasTail; public bool isMammal; public void ShowInfo() { Console.WriteLine("Kind: " + kindOfAnimal); Console.WriteLine("Color: " + color); Console.WriteLine("Legs: " + numberOfLegs); Console.WriteLine("Has Tail? " + hasTail); Console.WriteLine("Is Mammal? " + isMammal); } }

Тъй като полетата на класа Animal са по същество глобални променливи за този клас, то методът ShowInfo() може да ги използва директно, без да се налага да ги получава като параметри.

Извикване на метод, дефиниран в клас

Най-напред трябва да бъде създаден обект от дадения клас, а след това методът се извиква чрез този обект.

public static void Main(string[] args) { Animal myPet = new Animal(); // въвеждане на стойности в полетата myPet.ShowInfo(); }

Полета, методи и обекти

Когато в един клас са описани полета и методи, всеки обект от този клас притежава собствени копия от тези полета и чрез всеки обект може да бъде извикван всеки от описаните методи. При извикване методът работи с тези стойности на полетата, които са определени от обекта, чрез който е извикан метода.

Поради тази причина извикванията streetFighter.ShowInfo(); и desertKing.ShowInfo(); водят до различни крайни резултати.

Методи - обобщение и задача

Обикновено в даден клас има един или няколко метода, които ви позволяват да опишете определени действия, изпълнявани от (или със) обекти от този клас.

class Rectangle { public double width, height; public void DuplicateWidth() { width = 2 * width; } }

Задача: Да се върнем на класа Rectangle. Той вече има полета за ширина и височина, както и метод, който удвоява ширината. Как бихме добавили нов метод, който изчислява и връща лицето на правоъгълника? Нека да го наречем CalculateArea().

class Animal
{
public string kindOfAnimal, color;
public int numberOfLegs;
public void ShowInfo()
{
Console.WriteLine("Kind: " + kindOfAnimal);
Console.WriteLine("Color: " + color);
Console.WriteLine("Legs: " + numberOfLegs);
}
}
class Rectangle
{
public double width, height;
public void DuplicateWidth() { width = 2 * width; }
public double CalculateArea() { return width * height; }
}
class Program
{
static void Main(string[] args)
{
// Пример 1: Animal
Animal cat = new Animal();
cat.kindOfAnimal = "cat";
cat.color = "black";
cat.numberOfLegs = 4;
cat.ShowInfo();
// Пример 2: Rectangle
Rectangle rect = new Rectangle();
rect.width = 5;
rect.height = 10;
rect.DuplicateWidth();
double area = rect.CalculateArea();
}
}
