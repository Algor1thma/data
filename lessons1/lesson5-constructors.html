Добавяне на конструктори към класове

Конструктори

Описание на клас – да допълним ☺

В ООП при създаване на обект от даден клас се извиква специален елемент от този клас, наречен конструктор.

Ако при описанието на класа не е създаден конструктор, компилаторът автоматично добавя такъв – т.нар. служебен конструктор или подразбиращ се конструктор.

По структурата си конструкторът изцяло прилича на метод, но за него не се посочва <тип> и името му винаги съвпада с името на класа.

Пример за автоматично добавяне на конструктор:
class Animal { public string kindOfAnimal; public string color; public int numberOfLegs; public bool hasTail; public bool isMammal; } class Program { public static void Main(string[] args) { // Автоматично добавен конструктор се извиква тук: Animal desertKing = new Animal(); } }

Създаване на собствен конструктор

  • Автоматично добавеният конструктор записва във всички полета на класа неутрални (подразбиращи се) стойности според техния тип.
  • Включването на собствен конструктор позволява на програмиста да зададе начални стойности на полетата, както и да определи изпълнението на конкретни действия при създаването на нов обект.
  • Когато в класа има описан конструктор, компилаторът не добавя служебен такъв.
Пример за собствен конструктор:
class Animal { public string kindOfAnimal; public string color; public int numberOfLegs; public bool hasTail; public bool isMammal; public Animal() { kindOfAnimal = "undefined"; color = "unknown"; numberOfLegs = 4; hasTail = isMammal = true; Console.WriteLine("Undefined animal has been just created :)"); } } class Program { public static void Main(string[] args) { Animal idk = new Animal(); } }

Обща форма на конструктор

[<достъп>] <име-на-класа> ([<списък-с-параметри>]) { <тяло-на-конструктора> }

Най-често модификаторът за достъп до конструктора е public, макар че това не е задължително.

Конструктор, който няма параметри, се нарича конструктор по подразбиране. В един клас може да има едновременно конструктор по подразбиране и конструктор с параметри.

Конструктори – типична употреба

  • Конструктор по подразбиране се използва най-често за задаване на начални стойности на полетата, когато тези начални стойности са различни от подразбиращите се за съответния тип. Прилага се, когато е възможно да се създаде обект, без да има пълна информация за стойностите на неговите полета в момента на създаването му.
  • Конструктор с параметри се използва най-често когато по време на създаване на обекта е достъпна информация за стойностите на неговите полета. Тази информация се изпраща под формата на параметри и конструкторът копира техните стойности в съответните полета.

Конструктори – пример 1

class Car { string brand, model; int yearProd, engineVolume; public Car() { brand = "Undefined"; model = "To be specified"; yearProd = 1900; engineVolume = 600; } public Car(string br, string mod, int yP, int eV) { brand = br; model = mod; yearProd = yP; engineVolume = eV; } public void PrintData() { Console.WriteLine("This is " + model + " of " + brand); Console.WriteLine("Engine volume: " + engineVolume); Console.WriteLine("Year of Production: " + yearProd); } } class Program { public static void Main(string[] args) { Car auto1 = new Car(); auto1.PrintData(); Car myAuto = new Car("Toyota", "Avensis III", 2231, 2010); myAuto.PrintData(); } }

Конструктори – пример 2

class Person { string fName, lName; public Person() { Console.Write("Enter first name: "); fName = Console.ReadLine(); Console.Write("Enter last name: "); lName = Console.ReadLine(); } public Person(string fn, string ln) { fName = fn; lName = ln; } public void PrintFullName() { Console.WriteLine("Regards from " + fName + " " + lName); } } class Program { public static void Main(string[] args) { Person p = new Person("Kirk", "Hammett"); Person d = new Person(); p.PrintFullName(); d.PrintFullName(); } }

Два записа за инициализация на полетата на клас в конструктор

  • С име на параметър на конструктора различно от името на полето
  • Със съвпадащо име, но със задължително използване на ключовата дума this, когато записваме името на полето
class Coefficient { double val; // Начин 1 - с име на параметъра различно от името на полето public Coefficient(double initVal) { val = initVal; } } class Coefficient { double val; // Начин 2 - с ключовата дума this public Coefficient(double val) { this.val = val; } }

Конструктори - обобщение

Описание: Конструкторът е своеобразен метод без тип и с фиксирано име. Извиква се винаги при създаване на нов обект. Обикновено в даден клас има поне един конструктор, чрез който могат да бъдат зададени начални стойности на полетата на новосъздаващия се обект, както и да бъдат изпълнени определени действия по време на създаването на този обект.
class Rectangle { int width, height; public Rectangle() { width = height = 1; } public Rectangle(int w, int h) { width = w; height = h; } }
