Колекция от данни: Списък

System.Collections.Generic.List<T>

1. Защо да използваме списъци (List<T>)?

Масивите са бързи и удобни, но имат едно сериозно ограничение – фиксиран размер, който не може да се променя след създаването им. Колекцията List<T> решава този проблем: тя представлява динамична редица от еднотипни елементи, която автоматично се разширява при добавяне и се свива при изтриване на данни.

За да използваме списъци в C#, включваме пространството от имена в началото на файла:

using System.Collections.Generic;

3. Деклариране и инициализация

В ъгловите скоби <T> се посочва типът на елементите (int, double, string, char или собствен клас):

// Празен списък от цели числа (Count = 0) List<int> primeNumbers = new List<int>(); // Списък с начални стойности (Count = 2) List<string> students = new List<string>() { "Иван", "Петър" }; // Създаване на списък с копиране на елементите от масив int[] arr = { 10, 20, 30 }; List<int> copyList = new List<int>(arr);
Как работи паметта: Count срещу Capacity
Вътрешно List<T> пази елементите си в скрит масив с определен капацитет (Capacity).
  • Count е реалният брой добавени елементи в момента.
  • Capacity е размерът на заделения буфер в паметта (при празен списък е 0, при първо добавяне става 4, а при запълване автоматично се удвоява: 8, 16, 32...).

4. Свойства, индексиране и обхождане

Индексите в списъка винаги са от 0 до list.Count - 1. Достъпът за четене и промяна на вече съществуващ елемент става с квадратни скоби list[i].

// Четене на N елемента от конзолата (всеки на нов ред) int n = int.Parse(Console.ReadLine()); List<int> nums = new List<int>(); for (int i = 0; i < n; i++) { nums.Add(int.Parse(Console.ReadLine())); } // Обхождане с for (имаме достъп до индекса и можем да променяме елементи) for (int i = 0; i < nums.Count; i++) { Console.Write(nums[i] + " "); } // Обхождане с foreach (само за четене на стойностите) foreach (int x in nums) { Console.Write(x + " "); } // Бързо извеждане на един ред с разделител Console.WriteLine(string.Join(", ", nums));

5. Добавяне и вмъкване на елементи

  • Add(стойност) – добавя един елемент в края на списъка (най-бързата операция).
  • Insert(индекс, стойност) – вмъква елемент на посочения индекс (между 0 и Count включително). Всички елементи от тази позиция надясно се изместват с +1 индекс.
  • AddRange(колекция) – добавя цял масив или друг списък от елементи в края.
  • InsertRange(индекс, колекция) – вмъква поредица от елементи, започвайки от посочения индекс.

6. Премахване на елементи

При изтриване елементите след изтрития автоматично се изтеглят наляво, за да не остават „празни дупки“, а Count намалява:

  • Remove(стойност) – търси и изтрива само първото срещане на дадената стойност. Връща true при успех или false, ако елементът не съществува.
  • RemoveAt(индекс) – изтрива елемента на конкретния индекс. За изтриване на последния елемент се пише: list.RemoveAt(list.Count - 1);.
  • RemoveRange(индекс, брой) – изтрива определен брой последователни елементи, започвайки от посочения индекс.
  • Clear() – изтрива всички елементи наведнъж и нулира Count на 0.

⚠️ Чести грешки и важни уловки (Внимание!):
  1. Достъп до празен списък по индекс: Ако списъкът е празен (Count == 0), записът list[0] = 5; хвърля грешка ArgumentOutOfRangeException! Нови елементи се добавят с Add(5).
  2. Разлика между Remove(2) и RemoveAt(2) при List<int>: Remove(2) търси и трие числото със стойност 2, докато RemoveAt(2) трие елемента на трета позиция (индекс 2)!
  3. Изтриване по време на цикъл: Никога не изтривайте елементи вътре в foreach цикъл (води до грешка InvalidOperationException). Ако триете няколко елемента по условие с for, обхождайте списъка отзад напред (for (int i = list.Count - 1; i >= 0; i--)), за да не прескачате елементи след изместването на индексите!
