Оператор за многовариантен избор

Оператор switch

Многовариантен избор

Един възможен подход за организиране на многовариантен избор е употребата на if-else-if конструкция.

int markNum = new Random().Next(2, 7); string markTxt; if (markNum == 2) markTxt = "Слаб"; else if (markNum == 3) markTxt = "Среден"; else if (markNum == 4) markTxt = "Добър"; else if (markNum == 5) markTxt = "Много добър"; else markTxt = "Отличен";

Алтернативна възможност се предоставя чрез оператора switch.

switch (markNum) { case 2: markTxt = "Слаб"; break; case 3: markTxt = "Среден"; break; case 4: markTxt = "Добър"; break; case 5: markTxt = "Много добър"; break; default: markTxt = "Отличен"; break; }

Как работи операторът switch?

Организира избор между различни части от програмен код на базата на стойността на даден израз или единична променлива (наричани често селектор).

Селекторът трябва да води до стойност от целочислен тип, символен тип (char), текстов тип (string), логически тип (bool) или изброен тип (примерно DayOfWeek).

Отделните части програмен код, между които се прави избор, се обозначават с етикет, който има такава обща форма:

  • case <стойност>:
  • default: (Не може да има повече от един!)

Логика на изпълнение:

  1. Най-напред се изчислява стойността на селектора.
  2. Ако тази стойност съвпада със стойност, посочена в някой етикет, тогава се изпълняват командите след този етикет докато не се достигне команда break.
  3. Ако тази стойност не съвпада с нито една от посочените в етикети стойности, тогава се изпълняват командите, посочени след default. Ако няма такъв етикет, тогава не се изпълнява нищо.
Обединяване на случаи
В ситуации, където искаме да определим едно и също действие за няколко стойности, етикетите се изреждат един след друг:
case 4: case 6: case 9: case 11:
Не се добавят други разделители, освен стандартното :. Не е нужно етикетите да се изреждат в определен ред (нарастващ или намаляващ).

class Program {
static void Main() {
Console.Write("Enter the first operand: ");
double a = double.Parse(Console.ReadLine());
Console.Write("Enter the second operand: ");
double b = double.Parse(Console.ReadLine());
Console.Write("add or subt or mult or div: ");
string op = Console.ReadLine();
switch (op) {
case "add":
Console.WriteLine($"{a} + {b} = {a+b}");
break;
case "subt":
Console.WriteLine($"{a} - {b} = {a-b}");
break;
case "mult":
Console.WriteLine($"{a} * {b} = {a*b}");
break;
case "div":
Console.WriteLine($"{a} / {b} = {a/b}");
break;
default:
Console.WriteLine("Unknown operation!");
break;
}
}
}
