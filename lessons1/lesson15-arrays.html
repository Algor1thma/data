Едномерен масив

Масив

Масивите в езика С# представляват съвкупност от няколко еднотипни променливи. Те се наричат елементи на масива. Елементите са номерирани с числата 0, 1, 2, ... N-1. Тези номера се наричат индекси. Броят на елементите в даден масив се нарича дължина на масива.

Важна особеност: Индексите започват от 0, а не от 1! Първият елемент има индекс 0, а последният елемент има индекс N-1.

Създаване

За да се създаде масив, трябва да се определят типа на елементите, името на масива и броя на елементите (който не може да бъде променян после). Формата е:

тип[] име = new тип[брой];

Примери:

int[] testArray = new int[12]; // Всички първоначално са 0 double[] prices = new double[5000];

Достъп и запълване със стойности

Достъпът става чрез: масив[индекс]. Например: testArray[0].

Запълването може да стане елемент по елемент или чрез изброяване при създаването:

int[] points = {12, 34, 3, 19, 2, 10, 29};

Обхождане

Обикалянето през всички елементи (обхождане) се прави най-често с цикъл for. Всеки масив "знае" дължината си чрез свойството Length.

for (int i = 0; i < testData.Length; i++) { testData[i] = i * i; }

Вградени методи на класа Array

  • Сортиране: Array.Sort(масив) - подрежда елементите (най-често във възходящ ред).
  • Обръщане: Array.Reverse(масив) - обръща подредбата на елементите.
  • Търсене:
    • Array.IndexOf(масив, търсена_стойност) - връща индекса на първото срещане (или отрицателно число, ако няма).
    • Array.LastIndexOf(масив, търсена_стойност) - връща индекса на последното срещане.
  • Слепване: String.Join(разделител, масив) - връща низ, в който са залепени всички елементи, разделени с посочения разделител.
