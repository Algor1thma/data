Оператор за повторения

Цикъл for

Операторът за повторения for е най-удобен за използване, когато е необходим фиксиран брой повторения.

Запис на цикъла

for(инициализация; условие; обновяване) { // тяло на цикъла (оператори); }

Пример:

for(int i = 1; i <= 10; i++) { Console.WriteLine("I love summer!"); }

Начин на действие:

  1. Изпълняват се командите от частта „инициализация“.
  2. Проверява се „условие“. При резултат false повторенията спират (край на for). При резултат true се продължава нататък.
  3. Изпълняват се командите от „тяло“.
  4. Изпълнява се „обновяване“.
  5. Преминава се отново към стъпка 2.

Пример 1: Отпечатване на серия от числа

Да се създаде приложение, което прочита от конзолата две цели числа: начало и край на числов интервал, а след това отпечатва числата от интервала едно след друго, разделени от по един интервал.

public static void Main(string[] args) { int a, b; Console.Write("a: "); a = int.Parse(Console.ReadLine()); Console.Write("b: "); b = int.Parse(Console.ReadLine()); for (int i = a; i <= b; i++) { Console.Write($"{i} "); } Console.WriteLine(); }

Пример 2: Повторения на текст

В конзолата се въвеждат текст и естествено число n. Да се създаде програма, която да извежда този текст n пъти един след друг.

public static void Main(string[] args) { Console.WriteLine("Повтарящ се текст"); Console.Write("Въведете текст: "); string txt = Console.ReadLine(); Console.Write("Колко пъти да се повтори: "); int rep = int.Parse(Console.ReadLine()); for (int i = 1; i <= rep; i++) { Console.Write(txt); } Console.WriteLine(); }

Пример 3: Поредица от намаляващи числа

Да се изведат всички положителни числа, започващи от въведено от клавиатурата число, в намаляващ ред със стъпка 3.

Упътване: Началната стойност на брояча е въведеното число, защото това е най-голямото число (числата ще се нареждат в намаляващ ред).
public static void Main(string[] args) { Console.Write("Въведете положително число: "); int a = int.Parse(Console.ReadLine()); for (int i = a; i > 0; i = i - 3) { Console.Write($"{i} "); } Console.WriteLine(); }

Пример 4: Кратни на 5

Да се създаде програма, в която от клавиатурата се въвежда естествено число n. Програмата да извежда на екрана всички числа между 1 и n, които са кратни на 5.

public static void Main(string[] args) { Console.Write("n = "); int n = int.Parse(Console.ReadLine()); for (int i = 5; i <= n; i++) { if(i % 5 == 0) { Console.Write($"{i} "); } } Console.WriteLine(); }

Особености на цикъла for

Цикълът for е изключително гъвкав. Можем да пропуснем някои (или всички) от неговите елементи, стига да запазим разделителите ;.

1. С повече от една променлива

Можем да инициализираме и обновяваме няколко променливи едновременно, разделени със запетая:

int n = int.Parse(Console.ReadLine()); for (int i = 1, j = n; i <= j; i++, j--) { Console.WriteLine($"i={i}, j={j}"); }

Пример с вход и изход:

Вход: 5 Изход: i=1, j=5 i=2, j=4 i=3, j=3

2. Без инициализация

Ако променливата вече е декларирана и инициализирана преди цикъла, първата част може да остане празна:

int k = int.Parse(Console.ReadLine()); for (; k <= 3; k++) { Console.WriteLine(k); }

Пример с вход и изход:

Вход: 1 Изход: 1 2 3

3. Без стъпка (обновяване)

Обновяването на брояча може да се случи вътре в самото тяло на цикъла:

int max = int.Parse(Console.ReadLine()); for (int p = 1; p <= max; ) { Console.Write($"{p} "); p++; }

Пример с вход и изход:

Вход: 4 Изход: 1 2 3 4

4. Без начало и стъпка

Подобен запис работи абсолютно идентично на цикъла while:

int m = int.Parse(Console.ReadLine()); for (; m > 0; ) { Console.Write($"{m} "); m--; }

Пример с вход и изход:

Вход: 3 Изход: 3 2 1

5. Безкраен цикъл

Ако пропуснем всички елементи, получаваме безкраен цикъл. Той трябва да бъде прекъснат ръчно вътре в тялото чрез break:

for (;;) { string input = Console.ReadLine(); if (input == "stop") { Console.WriteLine("Спряно!"); break; // спираме го принудително } Console.WriteLine("Продължава..."); }

Пример с вход и изход:

Вход: test stop Изход: Продължава... Спряно!
