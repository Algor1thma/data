Работа с дата и време

Обекти DateTime и TimeSpan

1. Предназначение и приложение

Понякога се налага да имаме работа със специфични типове данни като дата и време. За тази цел в C# се използват обекти от типа DateTime. Всеки такъв обект съдържа информация за година, месец, ден, часове, минути, секунди и милисекунди.

2. Създаване на обект DateTime

Можем да създадем дата по няколко начина чрез конструкторите на класа:

  • new DateTime() – базов конструктор (дава 1.1.0001 г.)
  • new DateTime(year, month, day) – задава конкретна дата, часът е 00:00:00.
  • new DateTime(year, month, day, hour, minute, second) – задава дата и точен час.

3. Често използвани свойства

Свойства за вземане на текущото време:

  • DateTime.Now – съдържа текущата дата и време.
  • DateTime.Today – съдържа само текущата дата (часът е 00:00).

Свойства на самия обект:

Year, Month, Day, DayOfWeek, Hour, Minute, Second

Метод за проверка на високосна година:

bool isLeap = DateTime.IsLeapYear(year);

4. Интервал от време (TimeSpan)

Описва се чрез обект от типа TimeSpan. Има параметричен конструктор, в който се задават часовете, минутите и секундите. Например, new TimeSpan(17, 71, 125) ще се преобразува автоматично в правилни часове и минути.

5. Операции с дати

  • Добавяне: dt.Add(ts) добавя TimeSpan към дата.
  • Методи: AddYears(n), AddMonths(m), AddDays(d). Допускат се отрицателни стойности за връщане назад във времето.
  • Сравняване: Датите могат да се сравняват с > и <.
  • Разлика: При изваждане на две дати (newDate - oldDate) се получава обект TimeSpan, от който можем да вземем свойството .Days.

6. Задача: Откриване на петъците

Да се декларира клас FridayDemo с полета year и day. Класът да съдържа конструктор и метод FindFriday(), който извежда конкретния ден за всеки месец от дадената година, само ако се пада в петък.

if(dt.DayOfWeek == DayOfWeek.Friday) { Console.WriteLine(dt.ToString("dd MMMM yyyy")); }

class FridayDemo {
int year, day;
public FridayDemo(int y, int d) { year = y; day = d; }
public void FindFriday() {
Console.WriteLine("Петък:");
for(int month = 1; month <= 12; month++) {
DateTime dt = new DateTime(year, month, day);
if(dt.DayOfWeek == DayOfWeek.Friday)
Console.WriteLine(dt.ToString("dd MMMM yyyy"));
}
}
}
