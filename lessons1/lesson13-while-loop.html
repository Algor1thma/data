Оператор за повторения while

Цикли

Операторът while е най-удобен за случаи, при които броят на повторенията не е известен предварително, а зависи от някакво условие.

Запис на цикъла

while(условие) { // тяло на цикъла }

Пример:

while(myMoney < 1000000) { myMoney = myMoney * 1.05; years++; }

Начин на действие:

  1. Проверява се „условие“. При резултат false повторенията спират (край на while). При резултат true се продължава нататък.
  2. Изпълняват се командите от „тяло“.
  3. Преминава се отново към стъпка 1.
Важно! Ако условието е нарушено още отначало, командите в тялото на while няма да се изпълнят нито веднъж!

Пример 1: Последователи в Инстаграм

Джеймс установил, че последователите му се увеличават с 50% всяка седмица. Ако в началото е имал А последователи, след колко седмици ще има поне В последователи?

int a = int.Parse(Console.ReadLine()); int b = int.Parse(Console.ReadLine()); int weeks = 0; while (a < b) { a = (int)(1.5 * a); weeks++; } Console.WriteLine("Брой на седмиците: " + weeks);

Пример 2: Отрицателни числа

Да се състави програма, която въвежда последователност от цели числа, завършваща с 0, и извежда броя на отрицателните числа. Условието се повтаря докато въведеното число е различно от 0.

int a = -1, i = 0; while (a != 0) { a = int.Parse(Console.ReadLine()); if (a < 0) i++; } Console.WriteLine("Брой на отрицателните числа: " + i);

Пример 3: Средно аритметично

Програма за въвеждане на оценки (между 2 и 6). Въвеждането на 0 е сигнал за край. Да се изведе броят им и средното аритметично.

int mark = 1, qty = 0; double avrMarks = 0; while (mark != 0) { Console.Write("Оценка: "); mark = int.Parse(Console.ReadLine()); if (mark > 1 && mark < 7) { qty++; avrMarks += mark; } } avrMarks /= qty; Console.WriteLine($"Брой на оценките: {qty}"); Console.WriteLine($"Средна оценка: {avrMarks:f2}");
