Данни от знаков тип

За този тип се употребява названието char – съкращение от англ. дума “character” (знак). Ето пример за определяне на променлива от този тип:

char c;

Променлива от тип char съхранява стойности, които са единични знаци. Такива могат да бъдат например буквите от латинската или българската азбука, цифрите, както и препинателните знаци.

Типът char и Unicode

В езика C# знаците се представят с поредния си номер в двубайтовата таблица Unicode (2^16 = 65 536 знака). Стандартът Unicode е създаден с цел съхраняването на текстови данни на различни езици.

Знакова стойност
Присвояването на знакова стойност става чрез заграждането ѝ в единични кавички (апострофи):
char c = 'x';
За променлива от този тип може да се употреби метода ReadLine() (напр. c = char.Parse(Console.ReadLine());) и метода WriteLine(…).

Номер на знак и преобразуване

На всеки знак се съпоставя еднозначно номер. Например главната буква ‘A’ има номер 65, а знакът ‘@’ е с номер 64. В програма може да отпечатаме номера на един знак чрез кастване:

char c = 'A'; Console.WriteLine((int)c); // отпечатва 65

Получаването на числовата стойност от цифра (например '9') става чрез изваждане на символа '0':

char c = '9'; int i = c - '0'; // i съхранява числото 9

Достъп до знаците в символен низ

Тъй като всеки от знаците на даден низ е елемент на масив, той има позиция в низа и тя е индексът му в масива (започвайки от 0). Посредством индексиране може да се четат отделните знаци, но те не могат да се променят по този начин.

Char.ToUpper(c) – преобразува в главна буква.

💡 Практически приложения

Обработката на отделни символи стои в основата на почти всяка реална софтуерна система – от формите за регистрация до защитата на данни.

1. Проверка за сигурност на парола (Валидация)

При регистрация в уебсайт системата обхожда въведената парола символ по символ, за да провери дали съдържа поне една главна буква и поне една цифра:

string pass = Console.ReadLine(); bool hasUpper = false, hasDigit = false; for (int i = 0; i < pass.Length; i++) { if (Char.IsUpper(pass[i])) hasUpper = true; if (Char.IsDigit(pass[i])) hasDigit = true; } if (hasUpper && hasDigit) Console.WriteLine("Сигурна парола!"); else Console.WriteLine("Слаба парола!");
Вход: Secr3t Изход: Сигурна парола!

2. Криптиране на съобщения (Шифър на Цезар)

Тъй като зад всеки char стои код от таблицата Unicode, можем да изместваме буквите с определен брой позиции напред, за да скрием текста от чужди очи:

string word = Console.ReadLine(); string encrypted = ""; for (int i = 0; i < word.Length; i++) { char shifted = (char)(word[i] + 3); // изместване с 3 позиции encrypted += shifted; } Console.WriteLine($"Криптиран текст: {encrypted}");
Вход: ABC Изход: Криптиран текст: DEF

3. Извличане и сумиране на цифри от текст

Когато получаваме данни от баркод, ЕГН или сериен номер като текст, използваме изваждане на '0', за да превърнем символите в реални числа за математически изчисления:

string code = Console.ReadLine(); int sum = 0; for (int i = 0; i < code.Length; i++) { if (Char.IsDigit(code[i])) { sum += code[i] - '0'; } } Console.WriteLine($"Сума на цифрите: {sum}");
Вход: BG-409-X2 Изход: Сума на цифрите: 15

4. Статистика и анализ на текст

Текстовите редактори (като MS Word) анализират документа знак по знак, за да преброят буквите, цифрите и интервалите:

string text = Console.ReadLine(); int letters = 0, spaces = 0; for (int i = 0; i < text.Length; i++) { if (Char.IsLetter(text[i])) letters++; else if (Char.IsWhiteSpace(text[i])) spaces++; } Console.WriteLine($"Букви: {letters}, Интервали: {spaces}");
Вход: Аз обичам C#! Изход: Букви: 9, Интервали: 2
