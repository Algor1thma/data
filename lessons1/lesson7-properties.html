Свойства (Properties) на клас

Модификатори на достъпа. Свойства на клас

Достъп и капсулиране чрез свойства

C# предлага една възможност за осигуряване на достъп до защитени полета - създаване на особени елементи, наречени properties (на български се среща като свойства или атрибути). Описването и работата с тези т. нар. свойства е максимално улеснено.

Свойството е нещо като комбинация от променлива и метод – изглежда като променлива и с него се работи като с такава, но се описва по подобие на метод. Обикновено се „свързва“ с private поле и осигурява достъп до него. Този достъп може да е двупосочен (и за четене, и за запис), но може да бъде и само в една посока.

Свойства – начин на описване

public <тип> Име_на_свойството { get { return стойност; } set { команди за настройване; } }
  • В get се описва каква стойност да има свойството – какво да се получава, когато се спомене някъде името му. Най-често се връща стойността на свързаното private поле, но може и да е нещо друго, например комбинация от стойности на различни полета или друг израз.
  • В set се описва начин, по който да се провери дали дадена стойност е подходяща за записване в свързаното поле. Стойността е достъпна чрез служебната дума value. Най-често се използва if(...) конструкция.

Не е задължително да има set { ... }. Ако свойството не е свързано с едно конкретно поле, тогава няма set{...}.

Препоръчва се името на свойството да е същото като името на свързаното private поле, но изписано с главна начална буква.

Свойства (properties) в клас – пример за описание

class Person { private string fName, LName; //полета public Person(string fn, string ln) //конструктор { fName = fn; LName = ln; } public string FName //свойство към полето fName { get { return fName; } //get метод set //set метод { if(!string.IsNullOrEmpty(value)) fName = value; else throw new ArgumentException(); } } public void PrintFullName() { Console.WriteLine("Person full name " + fName + " " + LName); } }

Properties – пояснения за get и set

В set се описва какво (и дали) да се запише в „скритото“ поле, като value тук обозначава присвояваната стойност. В примера, при присвояването p.FName = "Hans-Dieter"; value е "Hans-Dieter" и тъй като това е стандартен текст (издържа проверката за валидност – не е празен низ), присвояването се извършва успешно.

В get се указва връщаната стойност, тоест какво да се „разбира“ под името на свойството.

Свойства (properties) в клас - възможности

  • Защитата чрез private достъп и създаването на свойство позволява да се осъществи по-добър контрол на полетата на класа.
  • Свойство може да има само „гетър“ и по този начин съответното поле се превръща в поле само за четене (read-only).
  • Свойствата и модификаторите за достъп осигуряват гъвкавост – програмистът може да промени скритата част от класа, без това да повлияе (и да налага промени) на използването на този клас.
