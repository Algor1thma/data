Задача 1: Оценяване на задачи

Конструктори в класове

За матурата по информатика се подготвят задачи от различни учители в България. Определен брой съдии дават оценка на всяка задача. Всеки съдия оценява дадена задача с цяло число между -3 и 3:

  • Оценка 3 означава: „Тази задача много ми харесва!"
  • Оценка -3 означава: „Тази задача изобщо не ми харесва!"
  • Оценка 0 означава: „Не мога да преценя дали да използваме тази задача."

Общата оценка на дадена задача се получава като средна стойност от оценките на всички съдии - т.е. сумата от оценките, разделена на броя на съдиите, даващи оценка.

Задачите се оценяват на два етапа:

  • I етап - задачата се оценява само от двама съдии от журито (големи експерти в областта на информатиката).
  • II етап - задачата се оценява от останалите съдии от журито (по-малки експерти в областта на информатиката).

Вашата задача е да напишете програма, която изчислява минималната и максималната възможна обща оценка на задачата, оценена от всички съдии.

Да се декларира клас RatingProblem със следните полета:

ПолеТипОписание
nцяло числообщ брой на съдиите (n > 2)
r1цяло числооценка на първия съдия (от -3 до 3 вкл.)
r2цяло числооценка на втория съдия (от -3 до 3 вкл.)

Класът да съдържа два конструктора:

  1. RatingProblem() записва:
    5 в n (най-вероятният общ брой на съдиите);
    1 в r1 (най-вероятната оценка, дадена от първия съдия);
    2 в r2 (най-вероятната оценка, дадена от втория съдия).
  2. RatingProblem (int n, int r1, int r2) записва стойностите на параметрите си в полетата n, r1 и r2.

В класа да се дефинират следните методи:

  1. Метод double GetTotal() изчислява и връща сумата на оценките на двамата съдии.
  2. Метод double CalcMinimum() изчислява и връща минималната възможна обща оценка на задачата.
  3. Метод double CalcMaximum() изчислява и връща максималната възможна обща оценка на задачата.
  4. Метод void PrintMinMax() извежда на екрана резултатите.

Като се използва класът RatingProblem, да се напише програма, която:

  • Създава обект от класа RatingProblem чрез подразбиращия се конструктор и показва резултатите чрез подходящия метод.
  • Въвежда от клавиатурата:
    - общият брой на съдиите n;
    - предварителната оценка на първия съдия r1;
    - предварителната оценка на втория съдия r2.
  • Създава обект от класа RatingProblem с параметри като числовите данни са въведените от клавиатурата.
  • Отпечатва на екрана резултатите.

class RatingProblem {
int n, r1, r2;
public RatingProblem() {
n = 5; r1 = 1; r2 = 2;
}
public RatingProblem(int n, int r1, int r2) {
this.n = n; this.r1 = r1; this.r2 = r2;
}
double GetTotal() { return r1 + r2; }
double CalcMinimum() {
return (GetTotal() + (n - 2) * -3) / n;
}
double CalcMaximum() {
return (GetTotal() + (n - 2) * 3) / n;
}
public void PrintMinMax() {
Console.WriteLine($"Total number of judges: {n}");
Console.WriteLine("Ratings of judges that have already rated:");
Console.WriteLine($" R1: {r1}");
Console.WriteLine($" R2: {r2}");
Console.WriteLine($"Min overall rating: {CalcMinimum():f2}");
Console.WriteLine($"Max overall rating: {CalcMaximum():f2}");
}
}
class Program {
static void Main() {
RatingProblem rp1 = new RatingProblem();
rp1.PrintMinMax();
Console.Write("Enter n, r1, r2: "); // (Въведени: 4, -3, -2)
int n = 4, r1 = -3, r2 = -2;
RatingProblem rp2 = new RatingProblem(n, r1, r2);
rp2.PrintMinMax();
}
}
