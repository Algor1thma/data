Задача 1: Разстояние между две точки в равнината

Методи в класовете

Да се декларира клас Pnts, определящ две точки от равнината с декартови координати и разстоянието между тях. Класът да има следните полета:

ПолеТипОписание
x1реално числоx координата на първата точка
y1реално числоy координата на първата точка
x2реално числоx координата на втората точка
y2реално числоy координата на втората точка

В класа да се дефинират следните публични методи:

  • void CreatePoints() - за въвеждане на данните от клавиатурата.
  • void ShowPoints() - за отпечатване на точките.
  • double Segment() - за намиране на разстоянието между двете точки по формулата:

    $Distance = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$
Концептуална визуализация

Използваме Питагоровата теорема ($a^2 + b^2 = c^2$), където катетите са разликите по осите X и Y.

class Pnts {
double x1, y1, x2, y2;
public void CreatePoints() {
Console.Write("point 1 (x): "); x1 = Convert.ToDouble(Console.ReadLine());
Console.Write("point 1 (y): "); y1 = Convert.ToDouble(Console.ReadLine());
Console.Write("point 2 (x): "); x2 = Convert.ToDouble(Console.ReadLine());
Console.Write("point 2 (y): "); y2 = Convert.ToDouble(Console.ReadLine());
}
public void ShowPoints() {
Console.WriteLine("Points:");
Console.WriteLine("point 1: " + x1 + "; " + y1);
Console.WriteLine("point 2: " + x2 + "; " + y2);
}
public double Segment() {
return Math.Sqrt((x2 - x1) * (x2 - x1) + (y2 - y1) * (y2 - y1));
}
}
class Program {
static void Main() {
Pnts pn = new Pnts();
pn.CreatePoints();
pn.ShowPoints();
double seg = pn.Segment();
Console.WriteLine("Distance between points: " + seg.ToString("f2"));
}
}
