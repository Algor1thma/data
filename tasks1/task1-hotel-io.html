Задача: Регистрация в хотел

Форматиран вход и изход (IO)

Да се декларира клас Hotel, който осигурява функционалност за изчисляването на приходи от реализираните нощувки в хотел. Класът да съдържа следните полета:

ПолеТипОписание
clientтекстклиент (гост) на хотела
dateOfArrivalдата/времедата на пристигане
dateOfDepartureдата/времедата на заминаване
bedsцяло числоброй легла
Стаите на хотела разполагат с легла от 1 до 4 броя.

Конструктор

Класът да съдържа публичен конструктор: Hotel(string cl, DateTime d1, DateTime d2, int b), който копира параметрите в съответстващите им полета.

Методи

В класа да се дефинират следните методи, като се прецени кои да са публични:

  1. Метод int CalcNumberOfNights() – изчислява и връща броя на нощувките в хотела.
  2. Метод double CalcSumForOvernightStays() – изчислява и връща сумата за нощувките. Изчислява се по формулата: Брой легла * Брой нощувки * Цена.

    Условия за цената:
    - До 3 (вкл.) нощувки: 40 лева
    - До 9 (вкл.) нощувки: 38 лева
    - Над 9 нощувки: 36 лева
  3. Метод void PrintReference() – извежда на екрана справка за престоя на клиент в хотела. Трябва да спазва стриктно следния табличен формат с подравняване:
Посетител: client Дата на пристигане Дата на напускане Брой легла Брой нощувки Сума за плащане ------------------------------------------------------------------------------------------------ dd MMMM yyyy dd MMMM yyyy beds ? ?

Пример:

Посетител: Горанов Дата на пристигане Дата на напускане Брой легла Брой нощувки Сума за плащане ------------------------------------------------------------------------------------------------ 20 юни 2020 25 юни 2020 2 5 380,00 лв. ------------------------------------------------------------------------------------------------

class Hotel {
string client;
DateTime dateOfArrival, dateOfDeparture;
int beds;
public Hotel(string cl, DateTime d1, DateTime d2, int b) {
client = cl; dateOfArrival = d1; dateOfDeparture = d2; beds = b;
}
int CalcNumberOfNights() {
return (dateOfDeparture - dateOfArrival).Days;
}
double CalcSumForOvernightStays() {
int n = CalcNumberOfNights();
if(n >= 1 && n <= 3) return beds * n * 40.0;
else if(n >= 4 && n <= 9) return beds * n * 38.0;
else return beds * n * 36.0;
}
public void PrintReference() {
Console.WriteLine($"Посетител: {client}\n");
Console.WriteLine("Дата на пристигане\tДата на напускане\tБрой легла\tБрой нощувки\tСума за плащане");
Console.WriteLine(new String('-', 96));
Console.WriteLine($"{dateOfArrival, 18:dd MMM yyyy}{dateOfDeparture, 23:dd MMM yyyy}{beds, 17}{CalcNumberOfNights(), 18}{CalcSumForOvernightStays(), 19:c2}");
Console.WriteLine(new String('-', 96));
}
}
class Program {
static void Main() {
DateTime dtArr = new DateTime(2020, 6, 20);
DateTime dtDep = new DateTime(2020, 6, 25);
Hotel h = new Hotel("Горанов", dtArr, dtDep, 2);
h.PrintReference();
}
}
