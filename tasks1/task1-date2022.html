Задача 1: Дата от 2022 година

Модификатори на достъпа. Свойства на клас

Да се декларира клас Date2022, който описва дата от 2022 година, като съдържа следните private полета:

ПолеТипОписание
monthцяло числономер на месец, число между 1 и 12 вкл.
dayцяло числономер на деня в месеца, число между 1 и 28/30/31

Класът да съдържа публичен конструктор:

Date2022(int m, int d), който да копира параметрите m в month и d в day.

Свойства (Properties):

Да се добавят публично достъпни свойства Month и Day, които да осигуряват достъп за четене и за запис в съответните полета. При запис да се добавят следните изисквания:

  • Допуска се записване на стойност за месец, само ако е число между 1 и 12 вкл.
  • Допуска се записване на стойност за ден, само ако е:
    между 1 и 28 (при month = 2)
    между 1 и 30 (при month = 4, 6, 9, 11)
    между 1 и 31 (при month = 1, 3, 5, 7, 8, 10, 12).
  • При невалидни данни да се хвърля изключение (Exception).
Летен сезон

Приемаме, че една дата се намира през лятото, ако попада точно в интервала между 22 юни и 22 септември включително.

Методи в класа:

  1. int GetDaysLeft() изчислява и връща броя на дните, оставащи от текущия ден до края на текущия месец. Например от 11 май до края на май остават 20 дни.
  2. bool IsInTheSummer() връща true, ако текущата дата е между 22 юни и 22 септември вкл.
  3. void Print() извежда на екрана информация във вида dd.mm.2022, показва дали е през лятото и колко дни остават до края на месеца.

Програма (Main метод):

  • Създава обект от класа Date2022 с фиксирани стойности (например 8 и 28).
  • Извежда информацията за обекта.
  • Организира въвеждане на нов месец и нов ден от клавиатурата и ги записва чрез свойствата.
  • Отново извежда информацията за обекта.

Примери за работа и изключения:

Дата: 28.08.2022 Това е през лятото Дни до края на месеца: 3 Въведете месец: 3 Въведете ден: 5 Дата: 05.03.2022 Това не е през лятото Дни до края на месеца: 26
Дата: 28.08.2022 Това е през лятото Дни до края на месеца: 3 Въведете месец: 14 System.ArgumentException: Невалидна стойност за месец!

private int month, day;
public Date2022(int m, int d) {
Month = m; Day = d;
}
public int Month {
get { return month; }
set {
if (value > 0 && value < 13) month = value;
else throw new ArgumentException("Невалиден месец!");
}
}
public int Day {
get { return day; }
set {
int max = 31;
if (month == 2) max = 28;
else if (month==4||month==6||month==9||month==11) max=30;
if (value > 0 && value <= max) day = value;
else throw new ArgumentException("Невалиден ден!");
}
}

Console.WriteLine($"Дата: {day:d2}.{month:d2}.2022");
