Задача 2: Заплата на служител

Методи в класовете

Да се декларира клас Employee, който пресмята заплатата на служител чрез следните полета:

ПолеТипОписание
hoursреално числочасове на работа
salaryреално числозаплата за 1 час

В класа да се дефинират следните публични методи:

  • void Read() - за въвеждане на стойностите за изработените часове и заплатата за 1 час.
  • double CalcTotalSalary() - за изчисляване на заплатата на служителя според изработените часове.
  • void PrintTotal() - за отпечатване на резултата. Този метод трябва да използва метода CalcTotalSalary().

class Employee {
double hours, salary;
public void Read() {
Console.Write("Hours: ");
hours = double.Parse(Console.ReadLine());
Console.Write("Salary: ");
salary = double.Parse(Console.ReadLine());
}
double CalcTotalSalary() {
return hours * salary;
}
public void PrintTotal() {
double total = CalcTotalSalary();
Console.WriteLine($"Total salary (hours * salary): {total:f2}");
}
}
class Program {
static void Main() {
Employee empl = new Employee();
empl.Read();
empl.PrintTotal();
}
}
