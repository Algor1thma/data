Задача 1: Годност на лекарства

Работа с дата и време

Да се декларира клас Medicament, чрез който се дава възможност за проверка на годността на лекарствата в аптека. Класът да съдържа следните private полета:

ПолеТипОписание
yearцяло числогодина на производство
monthцяло числомесец на производство
dayцяло числоден на производство
daysцяло числосрок на годност (брой дни)

Конструктор и Свойства:

Класът да съдържа публичен конструктор Medicament(int y, int m, int d, int ds), който да копира параметрите y в year, m в month, d в day и ds в days.

В класа да се дефинират следните публични елементи:

  1. Свойство ExpirationDate - при четене връща датата, на която изтича годността на лекарството (към датата на производство, образувана от полетата year, month и day, се добавя срокът на годност в дни чрез AddDays()). Свойството да не бъде достъпно за запис!
  2. Метод void Evaluation() - проверява и извежда съобщение за годността на лекарството към текущата дата в следния формат:
Към 19.10.2022 лекарството е годно за употреба. или Към 19.10.2022 лекарството не е годно за употреба!

На мястото на 19.10.2022 се извежда днешната (текущата към момента на изпълнение на програмата) дата!

Като се използва класът Medicament, да се напише програма, която:

  • Въвежда от клавиатурата на отделни редове: годината на производство, месеца, деня и срока на годност (в дни).
  • Създава обект m от класа чрез конструктора с параметри.
  • Извежда на екрана крайната дата на годност във формат dd MMMM yyyy чрез използване на свойството ExpirationDate със следния текст: Лекарството е годно до 13 май 2023
  • Извежда на екрана съобщение за годността на лекарството към настоящата дата чрез извикване на подходящия метод.

Цялостни примери:

Въведете година на производство: 2021 Въведете месец на производство: 5 Въведете ден на производство: 13 Въведете срок на годност (дни): 730 Лекарството е годно до 13 май 2023 Към 19.10.2022 лекарството е годно за употреба
Въведете година на производство: 2020 Въведете месец на производство: 12 Въведете ден на производство: 22 Въведете срок на годност (дни): 540 Лекарството е годно до 15 юни 2022 Към 19.10.2022 лекарството не е годно за употреба!

class Medicament {
private int year, month, day, days;
public Medicament(int y, int m, int d, int ds) {
year = y; month = m; day = d; days = ds;
}
public DateTime ExpirationDate {
get {
DateTime dt = new DateTime(year, month, day);
return dt.AddDays(days);
}
}
public void Evaluation() {
if (DateTime.Today <= ExpirationDate)
Console.WriteLine($"Към {DateTime.Today:dd.MM.yyyy} лекарството е годно...");
else
Console.WriteLine($"Към {DateTime.Today:dd.MM.yyyy} лекарството не е годно...");
}
}
class Program {
static void Main() {
// Пример 1: Годно лекарство
Medicament m1 = new Medicament(2021, 5, 13, 730);
Console.WriteLine($"Лекарството е годно до {m1.ExpirationDate:dd MMMM yyyy}");
m1.Evaluation();
// Пример 2: Негодно лекарство
Medicament m2 = new Medicament(2020, 12, 22, 540);
Console.WriteLine($"Лекарството е годно до {m2.ExpirationDate:dd MMMM yyyy}");
m2.Evaluation();
}
}
