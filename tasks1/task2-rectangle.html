Задача 2: Правоъгълник

Тематични задачи

Да се създаде конзолно приложение за описание на правоъгълник. В него да се декларира клас Rectangle със следните полета:

Поле Тип Описание
length реално число дължина на правоъгълника
width реално число ширина на правоъгълника

Да се извършат следните действия:

а) Да се създаде правоъгълник, като дължината и ширината му се инициализират чрез следните данни:

length width
7.7 4.9

б) Да се изчисли по формулата $S=a\cdot b$ лицето на правоъгълника.

в) Да се изведат на екрана полетата на правоъгълника, както и изчисленото лице.

Стартов код (Скелет): class Rectangle { // Декларирайте полетата тук } class Program { static void Main(string[] args) { // Напишете вашето решение тук... } }
Проследете създаването на обекта и изчисляването на лицето!
Обект: rect
🟦
length 0.0
width 0.0
Метод Main()
🧮
s (лице) 0.0
Rectangle rect = new Rectangle();
rect.length = 7.7;
rect.width = 4.9;
double s = rect.length * rect.width;

Console.WriteLine("Width: " + rect.width);
Console.WriteLine("S: " + s);
