Задача 1: Броячи на знаци

Символи и форматиране

Да се декларира клас CharCounter, който да подпомага създаването на програма за работа с текстови данни. Класът да съдържа следното поле:

ПолеТипОписание
strтексттекст, в който ще се търси

Конструктор

Класът да съдържа публичен конструктор: CharCounter(string s), който копира параметъра в съответстващото му поле.

Методи

В класа да се дефинират следните методи, като се прецени кои да са публични:

  1. Метод int CountUppers() – преброява и връща броя на главните букви в текста.
  2. Метод int CountLetters() – преброява и връща броя на всички букви в текста.
  3. Метод int CountSymbols() – преброява и връща броя на символите.
  4. Метод int CountSpaces() – преброява и връща броя на интервалите.
  5. Метод void PrintCounter() – отпечатва броя на всички главни букви, букви, символи и интервали в табличен вид. На първия ред се извежда текстът "Лексикографска справка".

Оформление на таблицата

Заглавният ред трябва да се оформи със следните подравнявания: "Главни букви" (без), "Букви" (дясно, 10), "Символи" (дясно, 12), "Интервали" (дясно, 14).

Брой на тиретата под заглавието и в края: 48.

Числови данни: за 1-ва колона (дясно, 6), 2-ра колона (дясно, 14), 3-та колона (дясно, 11), 4-та колона (дясно, 13).

Като се използва класът CharCounter, да се напише програма (Main), която: създава обект чрез въвеждане от клавиатурата и извежда информацията на екрана.

Пример:

💡 Практически приложения

Методи, подобни на тези в класа CharCounter, са в основата на много реални софтуерни решения.

1. Валидация на потребителски пароли

При създаване на акаунт системите изискват "сложна парола". За да проверят дали паролата е силна, те използват броячи за поне една главна буква, една малка буква, една цифра и един специален символ. Ако броячът върне 0 за някое от тези изисквания, паролата се отхвърля.

2. Ограничения в социалните мрежи (Twitter/X)

Платформи като X (Twitter) имат стриктен лимит от 280 символа на публикация. Те използват символни броячи в реално време, които променят цвета си в червено, когато потребителят надхвърли лимита.

3. SEO анализ на текстове (Copywriting)

Текстовите редактори и SEO инструментите (като Grammarly или Yoast) постоянно броят думите, интервалите и символите в текста. Тези метрики определят дали дадена статия е достатъчно дълга, за да се класира добре в Google.

class CharCounter {
string str;
public CharCounter(string s) { str = s; }
int CountUppers() {
int k = 0;
for(int i = 0; i < str.Length; i++)
if (Char.IsUpper(str[i])) k++;
return k;
}
int CountLetters() { /* Аналогично с IsLetter */ return 9; }
int CountSymbols() { /* Аналогично с IsSymbol */ return 2; }
int CountSpaces() { /* Аналогично с IsWhiteSpace */ return 5; }
public void PrintCounter() {
Console.WriteLine("Лексикографска справка:\n");
Console.WriteLine($"{"Главни букви"}{"Букви", 10}{"Символи", 12}{"Интервали", 14}");
Console.WriteLine(new String('-', 48));
Console.WriteLine($"{CountUppers(),6}{CountLetters(), 14}{CountSymbols(), 11}{CountSpaces(), 13}");
Console.WriteLine(new String('-', 48));
}
}
class Program {
static void Main() {
Console.Write("Въведете символен низ: ");
