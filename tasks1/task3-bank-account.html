Задача 3: Банкова сметка

Тематични задачи

Да се създаде конзолно приложение за описание и извеждане на данните на клиент на банката и неговата банкова сметка. В него да се декларира класа BankAccount, описващ подробности за собственика, за валутата и за текущата сума в банковата сметка.

Полета на класа BankAccount:

Поле Тип Описание
holderFirstName низ собствено име
holderLastName низ фамилно име
currencyCode цяло число код за валутата на сметката: 1- лева; 2- евро
amount реално число сума в банкова сметка

Да се извършат следните действия:

а) Да се създадат две банкови сметки със следните данни:

holderFirstName holderLastName currencyCode amount
Ilko Stoev случайно число: 1 или 2 случайно число между 10 и 10000
Matt Damon случайно число: 1 или 2 случайно число между 10 и 10000

б) Да се изведат на екрана имената на притежателите и наличностите по сметките, заедно с валутата (BGN или EUR).

в)* Да се изведе името на собственика на сметката с по-голяма наличност, като за обменен курс се използва 1 EUR = 1,96 BGN.

class BankAccount
{
public string holderFirstName;
public string holderLastName;
public int currencyCode;
public double amount;
}
class Program
{
static void Main(string[] args)
{
Random rnd = new Random();
BankAccount acc1 = new BankAccount();
acc1.holderFirstName = "Ilko";
acc1.holderLastName = "Stoev";
acc1.currencyCode = rnd.Next(1, 3);
acc1.amount = rnd.Next(10, 10001);
BankAccount acc2 = new BankAccount();
acc2.holderFirstName = "Matt";
acc2.holderLastName = "Damon";
acc2.currencyCode = rnd.Next(1, 3);
acc2.amount = rnd.Next(10, 10001);
// Отпечатване на данните (кодът за печат е скрит за краткост във визуализацията)
Console.WriteLine("Account holder name: " + acc1.holderFirstName + " " + acc1.holderLastName);
// ...
double totalBgn1 = acc1.amount;
if (acc1.currencyCode == 2) totalBgn1 = acc1.amount * 1.96;
double totalBgn2 = acc2.amount;
if (acc2.currencyCode == 2) totalBgn2 = acc2.amount * 1.96;
if (totalBgn1 > totalBgn2)
Console.WriteLine("Собственик с по-голяма наличност: " + acc1.holderFirstName);
else
Console.WriteLine("Собственик с по-голяма наличност: " + acc2.holderFirstName);
}
}
