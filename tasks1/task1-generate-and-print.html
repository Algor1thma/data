Едномерен масив

Да се декларира клас GPArr, който съдържа следните private полета:

ПолеТипОписание

Конструктор

Класът да съдържа публичeн конструктор GPArr(), който създава масива и извиква метода Fill().

Методи

В класа да се дефинират следните методи:

  1. Метод void Fill() – извършва запълването на масива със стойности чрез въвеждане от клавиатурата.
  2. Метод void PrintArray(string delim) – извежда на екрана числата от масива на един ред. Между всеки две числа се извежда разделителя delim. След последното число не се извежда разделител, а се преминава на нов ред.
  3. Метод void CheckSymm() – проверява дали масивът е симетричен (първият и последният елементи са равни, вторият и предпоследният също са равни и т.н.). Извежда на екрана съответното съобщение.

Да се напише програма (Main), която: създава обект, извежда масива (с разделител "; ") и проверява за симетрия.

Указание: Ако имате проблем с кирилицата в конзолата, добавете тези команди в началото на Main():
Console.OutputEncoding = System.Text.Encoding.Unicode;
Console.InputEncoding = System.Text.Encoding.Unicode;

Пример за несиметричен масив:

Съдържание на масива: 12; 5; 11; 4; 1; 4; 11; 5; 12; 10 Този масив не е симетричен!

Пример за симетричен масив:

Съдържание на масива: 12; 5; 11; 4; 1; 1; 4; 11; 5; 12 Този масив е симетричен!

class GPArr {
int[] arr;

void Fill() {
for(int i = 0; i < arr.Length; i++) {

}
}
public void PrintArray(string delim) {
Console.WriteLine(string.Join(delim, arr));
}
public void CheckSymm() {
bool sym = true;
for(int i = 0; i < arr.Length; i++) {
if(arr[i] != arr[arr.Length - 1 - i]) {
sym = false;
}
}
if(sym) Console.WriteLine("Симетричен!");
else Console.WriteLine("Не е симетричен!");
}
}
class Program {
static void Main() {
GPArr gp = new GPArr();
gp.PrintArray("; ");
gp.CheckSymm();
}
