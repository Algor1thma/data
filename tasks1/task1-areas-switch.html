Задача 1: Лица

Оператор switch

Да се декларира клас Area, който осигурава функционалност за изчисляване на лице на равностранен триъгълник, лице на квадрат и лице на кръг. Класът да съдържа следните полета:

ПолеТипОписание
shapeCodeцяло числокод на фигурата (1 за триъгълник, 2 за квадрат, 3 за кръг)
aреално числоизмерение на фигурата (страна или радиус)

Конструктор

Класът да съдържа публичен конструктор: Area(int _code, double _a), който копира параметрите в съответстващите им полета.

Методи

В класа да се дефинира следния метод, като се прецени дали да е публичен:

  • Метод void CalcArea() – изчислява и извежда лицето на фигурата в зависимост от кода или съобщение за грешка, ако кодът е невалиден. Данните да се извеждат с два знака след десетичния разделител.

Като се използва класът Area, да се напише програма, която:

  1. Организира диалог за въвеждане от клавиатурата на данни за код на фигурата и измерение на фигурата.
  2. Създава обект от класа Area, като използва въведените данни.
  3. Извежда на екрана информация за лицето на описваната от обекта фигура.

Примери за работа:

Въведете код за фигура (1, 2 или 3): 2 Въведете измерение: 3.5 Лице на квадрат S = 12.25 Въведете код за фигура (1, 2 или 3): 1 Въведете измерение: 10.25 Лице на триъгълник S = 45.49 Въведете код за фигура (1, 2 или 3): 3 Въведете измерение: 5 Лице на кръг S = 78.54 Въведете код за фигура (1, 2 или 3): 6 Въведете измерение: 2 Невалиден код - невъзможно намиране на лице!

class Area {
int shapeCode;
double a;
public Area(int _code, double _a) {
shapeCode = _code;
a = _a;
}
public void CalcArea() {
double s;
switch (shapeCode) {
case 1:
s = (a * a * Math.Sqrt(3)) / 4.0;
Console.WriteLine($"Лице на триъгълник S = {s:f2}");
break;
case 2:
s = a * a;
Console.WriteLine($"Лице на квадрат S = {s:f2}");
break;
case 3:
s = Math.PI * a * a;
Console.WriteLine($"Лице на кръг S = {s:f2}");
break;
default:
Console.WriteLine("Невалиден код - невъзможно намиране на лице!");
break;
}
}
}
class Program {
static void Main() {
Console.Write("Въведете код за фигура (1, 2 или 3): ");
int c = int.Parse(Console.ReadLine());
Console.Write("Въведете измерение: ");
double size = double.Parse(Console.ReadLine());
Area myShape = new Area(c, size);
myShape.CalcArea();
}
}
